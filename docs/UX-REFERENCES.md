## 🎬 Animation Libraries (Framer Motion, GSAP, etc.)

- [Awwwards · Animation](https://www.awwwards.com/websites/animation/) — sitios premiados con foco en animación
- [UI Movement](https://uimovement.com/) — feed diario de micro-animaciones de UI
- [LottieFiles](https://lottiefiles.com/) — animaciones vectoriales ligeras (Lottie/JSON)
- [Bruno Simon](https://bruno-simon.com/) — referente WebGL/Three.js interactivo
- [GSAP · Showcase](https://gsap.com/showcase/) — ejemplos reales con la librería que ya usamos
- [Framer Motion](https://www.framer.com/motion/) — API declarativa de animación para React
- [Codrops](https://tympanus.net/codrops/) — tutoriales y demos de efectos de vanguardia
- [Animista](https://animista.net/) — generador de animaciones CSS listas para copiar
- [Easings.net](https://easings.net/) — catálogo visual de curvas de easing
- [CSS Animation Rocks](https://cssanimation.rocks/) — recursos y técnicas de animación en CSS
